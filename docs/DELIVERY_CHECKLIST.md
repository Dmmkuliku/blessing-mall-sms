# Delivery Checklist — Blessing Mall SMS

Use this checklist when handing the system to the customer / institute.

## Before visit

- [ ] Project folder copied to USB (full folder, including `setup`, `docs`, `prisma`, `src`)
- [ ] Node.js LTS installer saved on USB (optional but recommended for offline Node install)
- [ ] Installation guide printed or PDF ready
- [ ] User manual printed or PDF ready
- [ ] Support contact details filled in the installation guide

## On the laptop

- [ ] Node.js 20+ installed
- [ ] Project copied to a permanent path (example: `C:\BlessingMall\blessing-mall-sms`)
- [ ] `setup\install.bat` completed successfully
- [ ] Desktop shortcut works
- [ ] First-run setup completed (shop name, owner password)
- [ ] Owner can open Dashboard
- [ ] Cashier can complete a test sale
- [ ] Manager can open Inventory and Purchases
- [ ] Receipt print dialog tested
- [ ] Database backup shown (`data\blessing-mall.db`)

## Security handover

- [ ] Temporary passwords explained and changed
- [ ] Owner understands Staff page for creating cashiers/managers
- [ ] Customer told not to delete the `data` folder
- [ ] Customer told to keep the Start console window open during trading hours
